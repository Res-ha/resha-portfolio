# Resha Portfolio

Personal website portfolio for Resha Ananda Rahman.

## 🎯 Features

- **6 Certifications** with logos from Cisco, DQLab, Digitalent
- **5 Projects** with GitHub links
- **12 Technical Skills** with icons
- **4 Work Experience** positions
- **Education** from Universitas Palangka Raya
- **Contact** via email, GitHub, LinkedIn

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm run dev
```

Available at: http://localhost:3003

## 📦 Deployment

Deploy to Vercel:

```bash
vercel login
vercel
```

Or connect custom domain in Vercel dashboard.

## 📁 Project Structure

```
src/
  data/       # resume.tsx - All personal data
  components/ # React components
    section/  # Section components (certifications, contact, etc.)
public/
  certification/  # Certification logos
  me.png        # Profile picture
  *.png         # Other logos
```

## 💻 Technologies

- **Next.js 16** - React framework
- **Tailwind CSS** - Styling
- **TypeScript** - Type safety
- **pnpm** - Package manager
- **content-collections** - Content management

## 📜 Template

This project was customized from the [magicuidesign/portfolio](https://github.com/magicuidesign/portfolio) template. The original template provides a solid foundation for personal portfolios, which was then customized with Resha's personal information, certifications, projects, and logos.

- **Original Template**: https://github.com/magicuidesign/portfolio
- **Customized For**: Resha Ananda Rahman
- **Customizations**: Resume data, certifications section, projects, skills, contact information
